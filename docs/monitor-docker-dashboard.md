# Docker Monitor 看板与改进记录

Docker 看板复用自定义 Monitor 的 SSH 命令采集、四种展示方式和连接覆盖配置。六个模块均为普通可编辑模块，可以排序、隐藏、修改命令或删除；新增模板不会替换现有模块。

## 配置方法

1. 连接安装了 Docker CLI 的 SSH 主机。当前 SSH 用户需要能以非交互方式执行 Docker 命令。
2. 在 Monitor 中选择 **新增模块 → Docker 看板**。
3. 选择保存位置。已保存的连接默认使用 **当前连接**，也可以选择 **全局默认**。
4. 查看模块与命令，点击 **添加 Docker 看板** 后开始采集。
5. 如只需 Docker 内容，可以在 **编辑布局** 中隐藏内置模块。模板再次添加时只补齐缺失模块，保留原有修改和顺序。
6. 在 **编辑布局 → 修改当前连接配置** 中选择 **双列** 或 **三列**。列数随配置保存；全局默认和连接覆盖可以使用不同列数。模块按从左到右、从上到下的顺序排列，可以跨列拖动。

选择多列时，主窗口会尝试展开右侧面板，也可以拖动面板左侧边缘调整宽度。每列至少保留 260 px，面板内容宽度达到 536 px 时显示双列，达到 812 px 时可显示三列；空间不足时自动减少显示列数，保留已选列数。旧配置默认单列。调整列数、排序或面板宽度不会重新创建采样任务或清空历史。

Docker 双列看板建议按“运行中容器、已停止容器、CPU 趋势、引擎信息、容器列表、容器资源”排序，让同类高度的模块并排。当前采用逐行网格，尚不支持模块跨列或瀑布流排版。

| 模块 | 数据来源 | 展示 | 刷新周期 |
| --- | --- | --- | --- |
| 运行中容器 | `docker info --format '{{.ContainersRunning}}'` | 整数 | 10 秒 |
| 已停止容器 | `docker info --format '{{.ContainersStopped}}'` | 整数 | 10 秒 |
| CPU 趋势 | `docker stats --no-stream` 的 CPU 百分比，使用 awk 校验并求和 | 最近五分钟曲线 | 10 秒 |
| 容器列表 | `docker ps -a --format '{{json .}}'` | JSON Lines 表格：名称、状态、运行状况、镜像、端口 | 10 秒 |
| 容器资源 | `docker stats --no-stream --format '{{json .}}'` | JSON Lines 表格：名称、CPU、内存、网络 I/O、磁盘 I/O、PIDs | 10 秒 |
| 引擎信息 | 格式化的 `docker info` | 文本：主机、版本、系统、架构、CPU 数 | 60 秒 |

完整命令与默认字段保存在 `src/lib/monitor-docker.ts`。CPU 和资源采集超时为 15 秒，其他模块为 10 秒；继续使用每会话最多两项并发及 256 KiB 输出限制。

模板需要 POSIX shell 和 awk，无需 jq、Python 或额外远端采集程序。所有模板命令仅读取 Docker 状态。Docker 命令错误会保留其退出状态；CPU 聚合不会将连接失败或非法百分比转换为零。成功采集且没有运行中容器时，CPU 为零，资源表为空。

总 CPU 是运行中容器的 CPU 使用量之和，100% 代表一个 CPU 核心，可以超过 100%。内存沿用 Docker CLI 的统计口径；网络和磁盘 I/O 为累计量，并非每秒速率。详见 [Docker stats 文档](https://docs.docker.com/reference/cli/docker/container/stats/)。

## 实际发现及完成的改进

| 不足 | 复现与影响 | 本次改进 |
| --- | --- | --- |
| Docker 原生 JSON 输出无法直接成为表格 | 对本机 30 条容器记录使用原 JSON 数组模式，得到 `invalidJson` | 新增显式 JSON Lines 输入格式；支持空结果、空行、CRLF；错误指出实际行号，仍保留缺失字段校验和 200 行上限 |
| 配置一个看板需要反复创建六个模块 | 手动填写命令、周期、字段、名称；重复添加容易产生重复采集 | 加入可预览的 Docker 模板，明确选择保存范围，按稳定 ID 幂等添加，只在确认添加后采集 |
| 字段映射需要逐个照抄输出 | 多列表格和嵌套 JSON 配置繁琐 | 试运行后可显式选择“使用输出中的字段”，生成最多 20 个映射；数值展示只选择有限数值字段，不会再次执行命令 |
| 带单位的数值不能直接画曲线 | `12.5%` 不满足完整有限数值规则 | CPU 模板在远端校验并聚合后输出数值；通用数值解析继续严格校验，资源表保留原始单位字符串 |
| 宽表撑大整列 | 336 px 的 macOS 原生侧栏中，表格使数字卡片、更新时间和曲线被右侧裁切 | 在 Monitor 内约束 Radix 滚动内容宽度，让表格独立横向滚动 |
| 窄侧栏不易浏览后续列 | 长容器名占满视野，系统隐藏滚动条时缺少明显入口 | 首列固定、长值截断并保留完整提示；加入左右列导航按钮及可聚焦的表格滚动区；预览中的导航不会提交编辑表单 |
| 单列布局无法利用较宽面板 | 六个 Docker 模块纵向堆叠，原右栏上限仅为窗口的 35%；横向拖动也不能触发排序 | 加入单／双／三列配置，支持按面板宽度自动回落；右栏最大宽度放宽至 70%，仍受终端最小宽度限制；拖动识别两个方向，跨列移动与切换列数保留采样历史 |
| 原生 WebView 重排后偶发文字未重绘 | 实际数字仍在、采集时间正常更新，但跨列移动后数字卡片会短暂或持续留白 | 模块使用独立合成层；macOS 中重复左右拖动后，数字和已有曲线均正常显示 |

新增文案均覆盖中文、英文和波兰文。原有配置不带 `tableFormat` 时继续按 JSON 数组解析；未新增脚本转换、正则解析或配置导入导出。

## 验收记录

2026-11-10 使用本机 Docker 29.8.2，通过独立的本地 SSH 测试入口，在 macOS Tauri 调试应用的实际 Monitor 组件中添加并保存了连接专属 Docker 看板。采集时为 10 个运行中容器和 21 个已停止容器，其中包含本次 SSH 测试容器。没有启动、停止或更改已有业务容器。

- 六个模板命令均通过真实 Docker 数据解析测试；数字、文本、CPU 曲线及两张表格通过真实 SSH 采集显示。
- 原生侧栏检查了 336 px 宽度、模板对话框、配置保存、固定首列和按钮横向查看；刷新后连接配置仍然存在。
- 自动化覆盖 JSON Lines 格式、空结果、错误行号、严格数值、嵌套字段建议、截取上限、幂等添加、范围隔离，以及试运行不自动保存或重复执行。
- CPU 聚合测试包含多核心超过 100%、无容器、Docker 非零退出及非法数值；失败不输出伪造的零值。

本次前端全量测试通过 1806 项，6 项真实 Docker 测试另行显式启用并全部通过；最终相关回归 47 项通过。Rust 测试通过 431 项，另有 1 项真实 SSH 输出限制、超时、取消及断开测试通过。构建与三语言一致性检查通过；全仓库 lint 为 0 错误、228 条警告，新增和修改的 Monitor 文件定向 lint 无警告。

多列布局增量验收（2026-11-10）：前端全量 1821 项通过，6 项真实 Docker 命令测试按默认设置跳过；构建和 1765 个翻译键检查通过，全仓库 lint 仍为 0 错误、228 条警告。macOS 原生 Monitor 中验证了 900 px 看板的双／三列、320 px 容器的单列回落、560 px 容器下三列设置回落为双列，以及左右跨列拖动和重启后的列数恢复。此次只改动前端布局，Rust 沿用 rebase 后 436 项通过的结果。

pnpm test

SSH 测试镜像位于 `src-tauri/docker/monitor-sshd/`，仅用于本机验收。它通过挂载 Docker socket 读取真实引擎状态；socket 访问权限并非只读授权，测试端口应仅绑定回环地址，验收后关闭测试容器。测试用户为 `testuser`，密码为 `testpass`，不可用于生产。

```bash
docker build -t rshell-monitor-sshd:local src-tauri/docker/monitor-sshd
docker run --rm -d --name rshell-docker-monitor \
  -p 127.0.0.1:2225:22 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  rshell-monitor-sshd:local
# 完成验收后
docker stop rshell-docker-monitor
```

## 仍待改进

- **重复采集**：数量模块分别执行 `docker info`，CPU 曲线和资源表分别执行 `docker stats`，并非同一次原子快照。后续可以支持共享数据源及一次采集供多个模块使用。
- **动态容器曲线**：当前提供总 CPU 趋势，尚不能自动为不断增删的容器维护独立曲线；可先为固定容器创建自定义命令。
- **大表浏览**：已有滚动、固定首列与截取提示，尚无筛选、列宽调整或独立全屏看板。
- **历史与告警**：采样只存在内存，五分钟之外的历史、重启续接和阈值告警尚未实现。
