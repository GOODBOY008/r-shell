Start with the computer you want to connect **from**. Install R-Shell on that computer, then connect to a host where you already have an account.

1. [Choose an installer and verify it](/docs/installation/).
2. [Connect over SSH and check the server identity](/docs/ssh/).
3. [Open a second terminal pane](/docs/terminal/) or [copy a file over SFTP](/docs/transfers/).

## Work with an existing connection

| What you want to do | Guide |
| --- | --- |
| See a remote desktop, adjust its resolution, or open it in a separate window | [RDP and VNC](/docs/remote-desktop/) |
| Compare hosts side by side or investigate one host's load | [Monitoring and dashboards](/docs/monitoring/) |
| Use saved connections and preferences on a second computer | [Cloud configuration sync](/docs/cloud-sync/) |
| Find a key binding or keep a terminal shortcut available to the shell | [Keyboard shortcuts](/docs/shortcuts/) |
| Work through a changed host key, update error, or failed connection | [Troubleshooting](/docs/troubleshooting/) |
