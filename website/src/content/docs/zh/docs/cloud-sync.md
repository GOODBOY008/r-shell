---
title: "跨设备同步配置"
description: "设置加密的 WebDAV 或 S3 兼容存储，在每台设备上核对首次合并的内容。"
---

在第一台电脑上打开「设置 → 云同步」。R-Shell 可同步保存的连接、分组、偏好、快捷键、命令片段，以及监控和看板定义。各台电脑需要访问同一个存储位置。

## 连接存储服务

| 服务 | 需要填写的信息 |
| --- | --- |
| WebDAV | 已存在的 HTTPS 目录地址、用户名和应用密码 |
| S3 兼容对象存储 | HTTPS 服务地址、签名区域、已有存储桶、可选对象前缀、访问密钥 ID 和 Secret。临时凭据还需要会话令牌。 |

使用自己的 Cloudflare R2 桶时，填写该桶的 S3 API 地址，区域填 `auto`，寻址方式选「路径式」。以前缀 `r-shell` 为例，加密快照会存为 `r-shell/r-shell-sync-v1.enc`。请把个人配置保存在自己控制的存储账号中。

1. 点击「测试连接」。R-Shell 会创建、更新并移除一个临时对象来验证条件写入，存储凭据需要有完成测试以及读写加密快照的权限。
2. 设置「同步加密口令」，并妥善保存一份。第二台设备需要用相同口令解密快照。
3. 按需选择是否在本机记住口令，以及是否「包含已保存的连接凭据」。默认关闭凭据同步。勾选「启用云同步」，然后保存设置。
4. 点击「保存设置并立即同步」。核对差异，为每个冲突选择「本机版本」或「云端版本」，然后点击「应用并同步」。
5. 在第二台电脑选择相同的服务、端点和目录或桶及前缀，输入相同的加密口令，并核对这台电脑的首次合并。

## 配对之后

私钥文件、本地密钥路径、SSH Agent 路径以及主机信任记录由每台设备各自保管。需要指定私钥文件的连接，要在新电脑上重新选择本地密钥。收到新的监控命令和目标后，先核对再启用采集。

应用打开期间会自动同步，本地修改稳定后、网络恢复时都会触发检查。选择「暂停自动同步」后仍可手动同步。预览期间云端版本发生变化时，刷新并重新核对差异。已使用的加密快照显示缺失时，先核对端点、桶和前缀，再决定是否配置新的存储位置。
