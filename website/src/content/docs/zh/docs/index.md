请在你平时操作的电脑上安装 R-Shell，并准备好一台已有登录账号的远程主机。

1. [选择并校验安装包](/zh/docs/installation/)。
2. [通过 SSH 登录并核对主机身份](/zh/docs/ssh/)。
3. [把终端分成两个窗格](/zh/docs/terminal/)，或[通过 SFTP 传输文件](/zh/docs/transfers/)。

## 使用已有连接

| 你想完成的操作 | 对应指南 |
| --- | --- |
| 查看远程桌面、调整分辨率或弹出独立窗口 | [RDP 与 VNC](/zh/docs/remote-desktop/) |
| 查看单台主机负载或并排比较多台主机 | [监控与看板](/zh/docs/monitoring/) |
| 把保存的连接和偏好带到另一台电脑 | [云端配置同步](/zh/docs/cloud-sync/) |
| 查找快捷键，或让终端按键交给 shell | [键盘快捷键](/zh/docs/shortcuts/) |
| 排查主机密钥变化、更新失败和连接问题 | [故障排查](/zh/docs/troubleshooting/) |
