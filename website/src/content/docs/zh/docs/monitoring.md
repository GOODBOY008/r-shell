「监视器」面板显示当前连接。要在同一视图中查看多台已保存的 SSH 主机，在左侧栏选择「看板」。

## 查看当前主机

选中已连接的终端，打开监视器面板，先查看 CPU、内存、系统负载和磁盘使用率。排查网络或服务问题时，可查看这台主机的接口和日志。可用日志来源取决于远程环境和 SSH 账号权限，包括日志文件、journalctl 和 Docker。

## 比较两台主机

1. 为每台主机分别保存一个 SSH 连接。
2. 打开「看板 → 浏览模板」，选择「Linux 主机」，为看板命名。
3. 为每个采集分组选中所需连接，点击「创建并开始采集」。看板会以标签形式打开，查看卡片上的主机名即可区分各台机器的读数。
4. 排查时可以切回终端标签，已打开的看板会在后台继续采集。需要停止采样时点击「暂停」。

![多主机看板并排显示两台 SSH 主机的请求量、延迟和服务就绪状态。](/media/multi-host-dashboard.webp)

模板以选定的 SSH 账号运行命令。例如，Docker 模板需要能使用 Docker CLI 并访问守护进程，NVIDIA GPU 模板需要 `nvidia-smi`。某张卡片提示错误时，先确认对应主机的权限和最后一次成功采样时间，再判断数值。

## 添加自定义读数

添加命令卡片，选定连接并填写非交互式命令。在试运行中查看标准输出、错误输出和退出状态，再决定如何显示。数值输出可用数值或曲线，结构化行可用表格，`uptime` 一类命令可用文本。同一采集源可供多张卡片复用。还可以添加 Markdown 卡片，把部署检查表放在指标旁边。
