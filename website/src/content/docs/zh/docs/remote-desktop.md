---
title: "使用 RDP 与 VNC"
description: "连接图形桌面，选择分辨率，并在工作区控制远程画面的显示方式。"
---

打开「新建连接」，选择远程电脑已启用的协议。主机地址和端口应能从当前网络或 VPN 到达。

## RDP

1. 选择 **RDP**。填写主机名或 IP、端口（通常为 `3389`）、用户名和密码。管理员提供了域名时，再填写域。
2. 可以先选「自动均衡（最高 1080p）」。远程桌面按窗口的逻辑像素调整大小，上限为 1920×1080。
3. 连接后，点击远程画面即可发送键盘和鼠标输入。工具栏支持全屏、「发送 Ctrl+Alt+Del」和「在独立窗口中打开」。
4. 需要让远程桌面始终保持同样大小时，在连接设置中选择固定分辨率，再用「适应窗口」在本机缩放图像。「Retina（高精细度）」会请求物理像素，画面更细，也需要更多带宽。

## VNC

选择 **VNC**，填写主机和服务端配置的端口（常用 `5900`），按需输入 VNC 密码。查看器支持键盘、鼠标、画面缩放，以及 Latin-1 字符范围的剪贴板文本。R-Shell 的 VNC 使用未加密的 RFB 传输，经过不受信任的网络时请使用 SSH 隧道。

## macOS 本地网络权限

macOS 15 及以上版本连接局域网主机或本地虚拟机时，可能弹出「本地网络」权限提示。请为已安装的 R-Shell 选择「允许」。连接仍提示“No route to host”时，在「系统设置 → 隐私与安全性 → 本地网络」核对 R-Shell 的权限，同时检查主机、VPN 和路由，再重新连接。
