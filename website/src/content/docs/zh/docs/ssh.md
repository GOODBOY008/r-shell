---
title: "通过 SSH 连接主机"
description: "建立终端会话、核对变更的主机密钥，并导入已有的 OpenSSH 配置。"
---

准备好服务器地址、SSH 端口、远程用户名和认证方式。如果服务器由他人维护，可向管理员确认这些信息。

1. 在连接管理器选择「新建连接」，协议选 **SSH**。
2. 填写主机地址、端口和远程用户名。SSH 通常使用 `22` 端口。为连接起一个便于识别的名称，要在侧栏保留它时勾选「保存为持久连接」。
3. 在「认证」中选择服务器支持的方式。密码认证使用远程账号密码。公钥认证需要选择这台电脑上的**私钥文件**。私钥已加密时，R-Shell 会提示输入密钥口令。
4. 点击「连接」。在新终端运行 `hostname` 和 `pwd`，确认主机与工作目录。从侧栏再次打开同一个已保存的连接，可以再开一个终端。

## 核对主机身份

启用默认主机密钥校验时，R-Shell 会把首次连接的主机记录在 OpenSSH 的 `~/.ssh/known_hosts` 中。如果服务器后来提供了不同的密钥，「主机密钥已更改」对话框会显示新指纹以及旧记录的位置。通过可信渠道向管理员核对指纹，确认相符后再点击「信任新密钥并连接」。选择取消会保留旧记录。

## 导入 OpenSSH 配置

在连接侧栏选择「导入 OpenSSH 配置」，选择文件后点击「预览」。默认文件为 `~/.ssh/config`。展开主机行，可以核对解析出的主机名、认证身份和跳板机。选中所需别名，导入目标分组。

导入后可以单独编辑这些连接。来源文件更新时，再次导入即可查看差异。同一字段在本地和来源都发生修改时，可以保留本地值，也可以选择来源值。经过跳板机时，每一跳都会单独核验主机密钥。
