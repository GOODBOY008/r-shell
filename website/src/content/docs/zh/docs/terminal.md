---
title: "终端标签与分屏"
description: "整理多个 SSH 会话、搜索终端输出，并重新接入后台会话。"
---

每个 SSH 终端标签都有自己的 shell 和当前目录。要同时观察服务状态和执行命令，可以打开两个会话并排使用。

## 并排使用两个终端

1. 从连接侧栏打开第二个会话。
2. 将标签拖向第一个终端的边缘，松开到左、右、上或下方的目标区即可分屏。拖到中间目标区，会加入同一个标签组。
3. 拖动窗格之间的分隔线调整大小。输入命令前先点一下目标窗格，当前标签显示将接收输入的主机。

![两个 SSH 窗格分别显示不同主机的部署输出和运行状态，下方显示远程文件。](/media/ssh-workspace.webp)

## 查找终端输出

点击终端后，在 macOS 上按 **⌘F**，在 Windows 和 Linux 上按 **Ctrl+Shift+F**。输入要找的文本，需要搜索模式时启用「使用正则表达式」，还可以开启「区分大小写」。搜索栏打开时，**F3** 跳到下一处匹配，**Shift+F3** 回到上一处。按 **Esc** 回到终端输入。

## 暂时收起会话

按 **Mod+Shift+H** 可以分离当前会话。只要 R-Shell 仍在运行，shell 就可以留在后台。在侧栏的「分离的会话」中选中它即可重新接入。重新启动应用时，会话恢复会按需连接先前保存的标签。如果任务需要在本机断开后继续运行，可在远程主机上使用 `tmux` 等工具。

**Mod** 在 macOS 上代表 Command，在 Windows/Linux 上代表 Control。终端获得焦点时可用的组合键见[键盘快捷键](/zh/docs/shortcuts/)。
