---
title: "传输文件与同步目录"
description: "上传、下载文件，查看传输队列，并在同步前核对两边目录的差异。"
---

在已连接的 SSH 会话中打开文件浏览器，即可用 SFTP 传输文件。只需要文件工作区时，可在「新建连接」中选择 SFTP 或 FTP。如果服务端使用基于 TLS 的 FTP，请在 FTP 设置中启用 **FTPS**。

## 上传或下载

1. 打开文件浏览器。「本地」窗格显示自己电脑上的文件，「远程」窗格显示已连接服务器上的文件。
2. 分别进入来源和目标目录。上传前先在远程窗格打开目标目录，下载前先在本地窗格打开目标目录。每个窗格都会显示传输目的地。
3. 在来源窗格选择文件或目录，再执行上传或下载。文件夹会递归传输。窄窗口下可点击「本地」「远程」或按 **F6** 切换窗格。
4. 展开底部传输队列，查看每项任务的进度、路径和错误。同时使用多台主机时，可按当前连接筛选。失败后先检查路径、权限和连接，再重试对应任务。

![本地与远程文件列表下方的传输队列显示了两个连接的任务。](/media/file-transfer-workspace.webp)

已知完整目录路径时，在目标窗格按 **Mod+L** 输入路径。编辑远程文本文件可选「在编辑器中打开」，从编辑器标签保存后，核对保存状态再关闭。

## 先比较目录，再同步

1. 打开要对比的两个目录，点击「比较 / 同步」。
2. 确认方向。「本地 → 远程」上传本地更改，「远程 → 本地」将更改下载到本机。
3. 选择比较条件，按需排除 `.git`、`node_modules` 等目录，再执行比较。
4. 按条目检查操作并勾选要应用的改动，尤其要核对标记为「删除」的条目。确认方向和两侧路径后开始同步。

文件传输处理的是目录与文件。要在另一台设备上复用连接和设置，请查看[云端配置同步](/zh/docs/cloud-sync/)。
