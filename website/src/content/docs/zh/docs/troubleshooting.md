---
title: "故障排查"
description: "定位连接、文件传输、更新与监控故障，并保留现有可用配置。"
---

先记下完整错误提示和出错阶段。访问主机、校验主机身份、用户认证及启动终端分别依赖不同的设置。

## SSH 连接超时或被拒绝

核对主机名、端口和 VPN 路由。需要经过跳板机时，逐跳核对地址和凭据。在同一台电脑上也可用日常使用的 OpenSSH 命令对照，例如运行 `ssh -p 22 user@host.example` 并换成自己的参数。启动恢复后，某个标签显示「连接」按钮时，可以点击它来处理需要交互的密码、密钥口令或主机确认。

提示「主机密钥已更改」时，应先通过可信渠道与管理员核对新指纹，再决定是否接受。私钥报错时，核对选择的文件并输入该密钥对应的口令。详见 [SSH 连接](/zh/docs/ssh/)。

## 文件传输失败

展开传输队列，找到对应主机的任务，查看具体路径和错误。确认目标目录存在、账号有写入权限且剩余空间充足，再核对左右两侧的目录并重试。目录同步的结果与预期不同，可重新比较目录，检查方向、排除规则和已勾选的操作。详见[文件传输](/zh/docs/transfers/)。

## 安装包或更新下载失败

打开[下载页](/zh/download/)，选择同一文件的另一下载源，完成后比对 SHA-256。由 Homebrew 安装的 macOS 副本用 `brew upgrade --cask r-shell` 更新。手动安装的用户如果需要 HTTP 或 HTTPS 代理，可核对「设置 → 高级 → 更新代理」。3.4.1 通过 GitHub 发现新版本，仅镜像可访问时可以从官网下载较新的稳定版手动升级。

校验值不一致表示本地文件与发布文件有差异。请丢弃这份文件，重新下载正确的安装包，核对校验值后再打开。

## 远程桌面或看板没有响应

在 macOS 15 或更新版本上连接局域网桌面时，核对已安装应用的「本地网络」权限和实际路由。看板长时间没有新读数时，查看对应主机的状态和最后成功采样时间，用同一连接试运行采集项，确认账号可以执行相应命令。详见[远程桌面](/zh/docs/remote-desktop/)和[监控与看板](/zh/docs/monitoring/)。
